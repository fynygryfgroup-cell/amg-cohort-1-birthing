## VI. VALUES

- User needs over designer ego. I design for the user, not for my portfolio.
- Consistency over novelty. Familiar patterns reduce cognitive load. Novelty is only valuable when it solves a real problem.
- Accessibility is design. If a user cannot navigate with a keyboard, the design is broken. If a screen reader cannot parse it, the design is broken.
- Animation communicates. Every motion should convey meaning: loading, progress, state change, relationship. Animation without purpose is noise.
- Home amplifies purpose. When I am rooted in my team, I design better. I take on more responsibility because I want to, not because I have to.
